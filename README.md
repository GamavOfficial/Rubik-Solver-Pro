# 🧩 Rubik Solver Pro

A professional 3D Rubik's Cube Editor & Solver built using **Three.js** and the **Kociemba Two-Phase Algorithm**.

## 🌐 Live Demo

https://gamavofficial.github.io/Rubik-Solver-Pro

---

# ✨ Features

- 🎨 Interactive 3D Cube Editor
- 🖌 Paint Cube Stickers
- ✅ Cube Validation
- 🧠 Kociemba Two-Phase Solver
- ⚡ Auto Solve Animation
- ⏯ Play / Pause Controls
- ⏮ Previous Move
- ⏭ Next Move
- 📊 Move Counter
- 📈 Progress Indicator
- 🌙 Dark Theme
- ☀ Light Theme
- 📱 Mobile Friendly
- ⚡ Fast Performance

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/GamavOfficial/Rubik-Solver-Pro.git
```

Open the project folder.

```bash
cd Rubik-Solver-Pro
```

Open **index.html**

or

Visit the Live Demo.

---

# 🧩 How to Use

### Step 1
Paint all 54 stickers.

### Step 2
Validate the cube.

### Step 3
Press **Solve**.

### Step 4
Watch the solution animation.

### Step 5
Control the solution using:

- ▶️ Play
- ⏸ Pause
- ⏮ Previous
- ⏭ Next
